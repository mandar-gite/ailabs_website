## Technology Stack

- **Framework**: [Astro](https://astro.build/) - Static site generator
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) - Utility-first CSS framework
- **Deployment**: GitHub Pages with GitHub Actions
- **Analytics**: Google Analytics 4 + Microsoft Clarity

## Project Overview

This is a static website for 72° AI Labs built with Astro and Tailwind CSS. The site showcases:

- Company information and services
- Project portfolio with detailed case studies
- Blog for technical insights and company updates
- Contact forms and lead generation

The website is optimized for performance, SEO, and static deployment on GitHub Pages.
