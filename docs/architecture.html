72° AI LABS Website — Architecture

Astro 5.x SSG + Tailwind CSS 3.x — deployed to GitHub Pages at 72ai.in

Stack

  • • Astro 5.x (static site generation)
  • • Tailwind CSS 3.x + CSS custom properties
  • • TypeScript (strict mode)
  • • @astrojs/sitemap + @astrojs/rss
  • • Formspree (serverless forms)
  • • GitHub Pages (hosting)
  • • GitHub Actions (CI/CD)

Architecture

  • • Pattern: Static SSG with file-based routing
  • • 20+ pages, 9 project detail pages
  • • Single Layout shell wrapping all routes
  • • Content Collections for blog (Zod schema)
  • • JSON data files for projects & solutions
  • • Exit-intent popup (session-scoped)
  • • Two visual themes: blue/white + navy/gold

Data Flow

  • • projects.json → solutions/ & projects/ pages
  • • solutions.json → solutions/index (groups)
  • • Blog MD → Content Collection → blog/ pages
  • • ContactForm → Formspree → /thanks
  • • Layout injects GA4 + Clarity + Apollo.io
  • • JSON-LD: Org, Service, Blog, FAQ, Breadcrumb
  • • RSS feed auto-generated from blog posts
