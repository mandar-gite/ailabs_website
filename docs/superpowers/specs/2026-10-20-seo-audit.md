# SEO audit, second pass (release 0.9.0 build)

Date: 2026-10-20. Audited build: `release/0.9.0` at `9853231`. Ahrefs returned "Insufficient plan" on every call, so there are no measured volumes, difficulty scores or backlink metrics. Search Console and web-search research are from the same day.

## Where the site stands

The technical base is solid after 0.9.0: a clean 22-URL sitemap, self canonicals, buyer-term titles on all 10 project pages, Lighthouse SEO 100 and accessibility 100. Search presence is close to zero. Google knows 12 pages, all 23 clicks are brand searches, and there's 1 backlink (linkedin.com).

## Findings this plan fixes

1. **Slashless internal links.** Nav, footer, project cards and blog cards link to `/projects`, `/blog`, `/solutions`, `/about`, `/privacy` and `/projects/<id>` without the trailing slash. Every one 301s on GitHub Pages. Counted in `dist/`: `/projects` 99, `/blog` 78, `/solutions` 77, `/about` 76, `/privacy` 50. Search Console reports the slashless URLs, which shows Google follows the hop. Blog JSON-LD has the same problem (`"item": "https://72ai.in/blog"`, BlogPosting `url` without slash), and `src/pages/en/careers.astro` canonicals to `https://72ai.in/careers`.
2. **Project pages are dead ends.** Each links out only to `/projects` (twice). No link to sibling projects in the same practice area, and none to the matching `/solutions/#<id>` section.
3. **Project pages have no structured data.** Blog posts carry BlogPosting, BreadcrumbList and FAQPage; project pages carry only the site-wide Organization graph.
4. **Blog posts don't link into the work.** Each post's body links only to `/#contact`. `/voice-dna` (the free tool) and `/about` get no in-content links from any page.
5. **Valent's lead misses its term.** "cap table" isn't in the first 100 words of `/projects/valent/`.

## Findings outside this plan

These need founder input or happen outside the codebase:

- Project pages are thin (73 to 213 words in `<main>`). Expanding them needs verified facts per project (client vs internal, real results).
- No INR pricing or "what a PoC looks like" page (needs price ranges).
- No blog post since 2026-04-14. Content gaps: private LLM and DPDP, self-hosted LLM vs ChatGPT, RAG vs fine-tuning, Tally/GST cluster, a Mumbai page.
- After deploy: submit `sitemap-index.xml`, request indexing for 8 pages, remove the unused Search Console TXT record, rerun Lighthouse live.
- Backlinks: directory listings, alumni network, guest posts.
